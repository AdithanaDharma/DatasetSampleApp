### Panduan Praktis Akuisisi Dataset Sampel Cairan

Panduan ini menjelaskan alur singkat penggunaan aplikasi untuk mengumpulkan dataset citra secara efisien.

---

#### Langkah 1: Memulai Sesi Baru
Setiap kali Anda memulai pengambilan data baru (misal: di hari yang berbeda atau kelompok sampel yang berbeda), mulailah dengan membuat sesi:
1. Tekan tombol **"Sesi Baru"** di pojok kiri bawah.
2. Muncul dialog nama sesi. Anda **tidak perlu mengisi nama** (langsung tekan "Mulai Sesi") jika ingin menggunakan nama otomatis berbasis tanggal.
3. Aplikasi akan membuat folder baru agar foto-foto Anda tidak tercampur.

[SCREENSHOT: Tombol Sesi Baru dan Dialog Sesi]

---

#### Langkah 2: Pengambilan Foto (Capture)
1. Posisikan gelas sampel tepat di dalam **kotak Bounding Box** di tengah layar.
2. Gunakan garis **Grid 3x3** untuk memastikan gelas tegak lurus dan simetris.
3. Tekan **Tombol Shutter** (bulat putih besar di sisi kanan) untuk mengambil gambar.

> **Catatan Penting:** Jika muncul peringatan teks merah *"Posisi sample belum pas"* padahal gelas menurut Anda sudah berada tepat di dalam kotak, **abaikan saja peringatan tersebut** dan silakan langsung mengambil foto.

[SCREENSHOT: Antarmuka Kamera Utama dan Bounding Box]

---

#### Langkah 3: Pratinjau dan Verifikasi
Setelah tombol shutter ditekan, Anda akan masuk ke layar pratinjau:
1. Periksa kualitas foto. Pastikan tidak blur dan pencahayaan sudah baik.
2. Jika foto kurang memuaskan, tekan **"Foto Ulang"** untuk kembali ke kamera.
3. Jika foto sudah bagus, tekan **"Gunakan Foto"**.

[SCREENSHOT: Layar Pratinjau Hasil Foto]

---

#### Langkah 4: Pemilihan Kategori
Aplikasi akan menampilkan pilihan kategori kualitas cairan:
1. Pilih salah satu kategori: **Baik**, **Normal**, atau **Buruk**.
2. Aplikasi akan secara otomatis memberikan nomor urut (**Image ID**) dan (**Sample ID**) sehingga Anda tidak perlu mengetik apa pun.
3. Setelah dipilih, foto otomatis dipindahkan dari folder sementara ke folder kategori di dalam sesi tersebut. Anda akan langsung kembali ke kamera untuk sampel berikutnya.

[SCREENSHOT: Dialog Pilihan Kategori]

---

#### Langkah 5: Selesai dan Kirim Data
Jika seluruh sampel sudah selesai diambil:
1. Tekan tombol **"Selesai (Zip)"** (ikon berbagi/share) di baris bawah.
2. Tunggu proses kompresi folder menjadi file `.zip` selesai.
3. Menu berbagi akan muncul otomatis. Pilih **WhatsApp** untuk mengirimkan seluruh dataset tersebut ke komputer atau tim riset Anda.
